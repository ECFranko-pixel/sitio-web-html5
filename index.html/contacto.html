Sobre esta sección

Elementos de formulario utilizados

El formulario utiliza los elementos de formulario de HTML5: el contenedor form, las etiquetas label asociadas a cada campo mediante los atributos for e id, los campos input para el nombre, el correo y el asunto, el área de texto textarea para el mensaje y el botón button de envío. El navegador valida automáticamente que el correo tenga un formato correcto gracias al tipo email.

Validación en el navegador

Los campos marcados con un asterisco son obligatorios. Esta validación básica en el navegador mejora la experiencia del usuario antes de enviar cualquier dato al servidor, siguiendo las buenas prácticas estudiadas en la asignatura.

Sobre este proyecto

Sitio web estático desarrollado con HTML5 como proyecto académico de la asignatura Tecnologías Web de la UTPL, correspondiente a las Unidades 2 y 3 de la guía didáctica.
